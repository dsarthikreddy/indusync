## 4. Decisions already made — do NOT revisit without a measured reason
- **TLS buffers go to PSRAM** (`v9TlsCalloc` + `mbedtls_platform_set_calloc_free` in v9Setup). Board package uses
  CONFIG_MBEDTLS_INTERNAL_MEM_ALLOC; internal RAM is only ~20-70 KB free (Wi-Fi + BLE + camera). Removing this brings back
  "esp-sha: Failed to allocate buf memory" and all cloud calls failing.
- `v9Http` refuses to start a TLS call when the largest internal block < 10 KB or DMA block < 6 KB (code -100 = "waiting for free memory", retried in 2 s, not counted as failure).
- **POST must NOT follow redirects** (Apps Script answers 302 after running doPost; HTTPClient follows 302 even in STRICT mode and lands on a 400 page). GET uses STRICT follow.
- Intervals sized for free tiers: commands poll 15 s, Telegram poll 30 s, status 30 s (+ push 8 s after OLED change), ThingSpeak 20 s alternating A/B, Blynk 240 s. Max backoff 60 s.
- Firestore event doc id = `door-1_<seq>` (idempotent); events create-once, retry must be identical; never edited/deleted.
- Firestore roles via `members/{email}`: admin / viewer / device (door-1.board@sarthik.room) / reporter (sheet.reporter@sarthik.room). One-time first-admin bootstrap via config/bootstrap. Nobody changes own role.
- Website "door online" = heartbeat < 3 min.
- Apps Script must NOT use GmailApp (the ungranted Gmail scope blocked the whole web app with 403/400).
- Board->Sheet instant path: only entries/warn/alert, skips events older than 10 min; Sheet dedupes via CacheService `ev:<id>` (6 h); route() is the 1-minute safety net and also e-mails. E-mail cap: entries stop at 70/day, alerts at 95.
- Laptop webhook sends "all"; Sheet keeps only CCTV_KEEP_ types; cctv_seen max once/30 min/person; laptop copies of door events (source "door") are ignored.
- Blynk: board learns missing pins (mask) and re-probes every 10 min; "doesn't have any value yet" on V10 = value 0.
- Telegram commands accepted only from TG_CHAT_ID (chat ids read as text: 10-digit ids overflow 32-bit).
- QR_SECRET lives in secrets.h and must equal SECRET_KEY in make_pass.py.

## 5. Hardware facts / gotchas
- Board: ESP32-S3-N16R8 CAM, camera GC2145 (RGB565, 240x240), pins in hardware/pinout.md.
- Only GPIO 38, 39, 40 are free and DIGITAL ONLY. No free analog pin (ADC1 pins used by camera; ADC2 unusable with Wi-Fi) -> analog sensors via ADS1115 on I2C SDA41/SCL42 (shared with OLED, 0x48/0x49).
- RC522 RST is wired to 3.3 V (RFID_RST 255). Never feed 5 V into GPIOs/ADS1115 inputs.
- `cam_hal: EV-VSYNC-OVF` in Serial = harmless dropped frame.
- Power the board from a 5 V 2 A charger for 24/7 (laptop sleep cuts USB power).
- Never type in Serial while testing: clear, forget <name>, resetphones, clearpasses (they delete data).
