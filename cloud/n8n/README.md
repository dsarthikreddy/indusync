# n8n (laptop only)
The 2 workflows are GENERATED by `tools/setup_stage3.py` (function `n8n_workflow`) because they contain the
private Sheet address + key. They are written to `5_n8n/generated/` on the laptop and imported into `5_n8n/n8n_data`.
Never commit `generated/`, `n8n_data/` or `n8n.env`.
- "SARTHIK Room - weekly and monthly reports": Schedule (every hour) -> HTTP GET <sheet>/exec?key=..&action=reports
- "SARTHIK Room - door watchdog": Schedule (every 10 min) -> HTTP GET <sheet>/exec?key=..&action=watchdog
All logic (catch-up, alert-once) lives in the Google Sheet script, so the workflows are only a timer + one web request.
