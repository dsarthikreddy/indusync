# CLASSYNC 4.0 — "SARTHIK Room" smart door, attendance and cloud monitoring
ESP32-S3 door board (RFID + on-board face recognition + signed visitor QR passes + Bluetooth phone key) that keeps
working offline, with a 24/7 Firebase website, Google Sheet records and e-mail, Telegram alerts, ThingSpeak graphs,
Blynk panel, n8n reports, Sentry and UptimeRobot monitoring, plus a laptop CCTV cross-check website.
VLSI part: 2.4 GHz and 13.56 MHz CMOS LNAs and a 4-bit R-2R DAC (Cadence Virtuoso).
